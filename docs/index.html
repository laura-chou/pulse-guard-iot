PulseGuard IoT

A professional-grade remote health monitoring solution integrating ESP32, Python, and Streamlit. Features dual-core real-time scheduling, EMA stream noise reduction, and automated report generation with active push notifications.

System Architecture

Topology & Data Flow

Quick Start

1. Firmware Deployment

Flash firmware.ino to ESP32. Configuration is handled via WiFiManager on first boot.

2. Backend Setup

Run backend/main.py to start the MQTT stream processor and health logic engine.

3. Visualization

Launch analytics/app.py for long-term health trend analysis and reporting.

Core Technology Stack

Firmware: Real-time Scheduling

C++ / FreeRTOS dual-core task management. Core 1 handles 100Hz sensor sampling and local UI, while Core 0 manages WiFi/MQTT communication to ensure zero-jitter data capture.

Backend: Stream Processing

Python-based engine with EMA (Exponential Moving Average) noise filtering. Implements 'Single Source of Truth' medical logic for consistent status evaluation across all platforms.

Analytics: Data Insights

Streamlit dashboard with automated health report generation. Features Plotly-powered physiological trend charts and multi-environment (prod/test) data isolation.

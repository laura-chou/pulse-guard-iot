快速開始 Quick Start

1. 安裝環境與依賴項目 Setup Environment & Dependencies
bash 
# 安裝後端與儀表板依賴
pip install -r backend/requirements.txt -r analytics/requirements.txt
2. 啟動數據處理器與儀表板 Run Stream Processor & Dashboard
bash 
# 終端機 A: 啟動 MQTT 數據流處理器 (負責保存至 MongoDB)
python backend/stream_processor.py

# 終端機 B: 啟動 Streamlit 視覺化儀表板
streamlit run analytics/app.py
3. 生成測試模擬數據 Generate Mock Data (Optional)
bash 
# 生成 6 個月的模擬歷史數據進行展示
python backend/generate_mock_data.py

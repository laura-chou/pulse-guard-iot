Technical Deep Dive 核心技術深度解析

📟

1. Firmware: High-Precision Edge Computing 1. 韌體端：高精度邊緣計算

Built on the ESP32 with FreeRTOS, the firmware ensures that sensor sampling is never interrupted by networking overhead. 基於 ESP32 與 FreeRTOS 即時作業系統，確保感測器採樣不受網路通訊延遲影響，實現穩定的生理訊號捕捉。

  • Dual-Core Orchestration:雙核任務調度： Dedicates Core 1 strictly to 25Hz I2C sampling for the MAX30102 sensor to maintain signal integrity, while Core 0 handles MQTT pub/sub and Wi-Fi state management. 將 Core 1 獨佔用於 MAX30102 的 25Hz 高頻採樣以確保訊號完整性；Core 0 則負責 MQTT 協議封裝與 Wi-Fi 連線維護。
  • Smart State Machine:智慧狀態機： Real-time "Finger-off" detection logic. If no sensor activity is detected for 20 seconds, the system triggers a "RESET" signal and enters Deep Sleep mode to maximize battery life. 內建「離手偵測」邏輯。若連續 20 秒未感測到生理訊號，系統將發送 RESET 訊號並自動進入深度睡眠模式。

2. Backend: Stream Processing & Analytics 2. 後端：串流處理與智慧分析

The Python backend acts as the brain of the system, filtering noise and determining health status in real-time. Python 後端作為系統大腦，負責即時過濾生理雜訊並進行深度的健康狀態判定。

  • EMA Noise Reduction:EMA 指數降噪演算法： Implements Exponential Moving Average (EMA) to smooth out hardware-induced fluctuations, ensuring that the health dashboard displays meaningful trends rather than raw jitter. 實作 EMA 演算法對 BPM 與 SpO₂ 進行平滑處理，有效消除環境干擾與硬體抖動產生的極端值。
  • Dual-Track Health Logic:雙軌制健康評估邏輯： A sophisticated evaluation system that monitors both individual data points (DANGER/WARNING) and whole-session stability (Persistent Danger vs. Sudden Abnormality) to provide accurate medical remarks. 結合單點閾值監控與區間統計分析，區分「持續性風險」與「突發性異常」，並自動生成專業的 LINE Flex Message 健康報告。
🧠
Intelligent Backend

3. Analytics: Data Visualization & Insights 3. 分析端：數據視覺化與洞察

The Streamlit-based dashboard provides a powerful interface for both patients and developers to review historical trends. 基於 Streamlit 的分析看板為使用者與開發者提供了強大的介面，用於回溯歷史趨勢與系統表現。

  • Multi-Environment Switching:多環境無縫切換： Supports dynamic data source switching via URL parameters (`?env=test`), allowing developers to verify features in a sandbox without polluting production medical data. 支援透過 URL 參數 (`?env=test`) 進行環境切換，確保開發測試數據與正式醫療紀錄完全隔離。
  • Interactive KPI Monitoring:互動式 KPI 監控： Features a 3-column KPI layout for critical events and leverages Plotly for responsive, high-resolution physiological charts. 整合 Plotly 互動式圖表與 Ag-Grid 異常紀錄過濾，快速定位生理數據中的風險時段。

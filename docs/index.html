⚡ 韌體端：高效即時採樣

基於 ESP32 雙核心架構，PulseGuard 韌體端實現了生理數據的精準採樣與即時處理：

  • ✅ 多核心任務分配：Core 0 處理 MQTT 網路通訊，Core 1 負責 MAX30102 高頻採樣。
  • ✅ 低功耗管理：內建 20 秒「手指脫離」自動休眠機制，配合物理按鍵喚醒。
  • ✅ 即時反饋系統：TFT 顯示波形，搭配三色 LED 與蜂鳴器實現生理狀態實時警報。
FreeRTOS I2C Protocol Deep Sleep

🐍 Python 後端：智慧數據分析

核心運算引擎負責將原始數據轉化為可臨床參考的健康洞察：

  • ✅ EMA 平滑演算法：採用指數移動平均與 15 秒滑動視窗，有效抑制感測器雜訊與突發性抖動。
  • ✅ 雙軌制健康判定：整合即時生理門檻值與 Session 統計分析，區分「暫時波動」與「持續危險」。
  • ✅ 自動化 LINE 報告：量測完成後自動生成 Flex Message 報告，包含醫療建議備註。

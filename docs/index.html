PulseGuard AIoT

整合 ESP32、Python 與 Streamlit 的全方位遠端健康監控解決方案，提供即時生理數據採樣與智慧化分析。 A comprehensive remote health monitoring solution integrating ESP32, Python, and Streamlit.

核心功能特色 Core Features

📟

韌體端：高效即時採樣

基於 FreeRTOS 雙核架構，在 Core 1 進行高頻感測器採樣，並透過 Core 0 處理 MQTT 異步通訊。

  • 25Hz 高頻生理數據採樣 (MAX30102)
  • FreeRTOS 任務優先級管理
  • 自動化省電模式與低功耗運行
🐍

Python 後端：智慧數據分析

採用 Python 異步處理技術，結合 EMA 平滑演算法與雙軌制評估邏輯，過濾雜訊並精準判斷健康趨勢。

  • EMA 指數加權移動平均演算法
  • MongoDB 雲端大數據存儲與查詢
  • LINE Notify 即時健康異常警示
📊

Streamlit：多維度視覺化

打造專業級數據儀表板，將生理紀錄轉化為直觀圖表，並提供多語系支援與歷史報告匯出。

  • 動態即時趨勢圖與 KPI 監控看板
  • 跨平台 RWD 回應式網頁設計
  • 多語系（中/英）一鍵切換介面

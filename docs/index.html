核心功能特色

📊

實時監測與分析

透過 ESP32 與 MQTT 實現低延遲數據傳輸，後端導入 EMA (指數移動平均) 濾波演算法，精準判定生理健康狀態。

💬

LINE 自動化報告

量測結束後即時推播 LINE Flex Message，提供單次工作階段的生理指標統計、異常分析與醫療建議備註。

📈

深度的數據洞察

基於 Streamlit 的數據分析平台，提供長期健康趨勢視覺化、每週異常事件統計與歷史日誌追蹤。
